## Data set
Датасет из 100 изображений (PNG и JPG) включает разнообразные позы, внешность людей, фоны и ракурсы. Такое разнообразие необходимо для тестирования: оно позволяет оценить, как модель определяет скелет человека в зависимости от этих факторов.

### Архитектура модели MediaPipe
>[!IMPORTANT]
>Архитектура MediaPipe построена по принципу графа обработки данных, где поток данных направляется между узлами, образуя направленный ациклический граф, способный к ветвлению и слиянию потоков. Основной единицей передачи данных в этом графе является пакет, который содержит числовую временную метку  и неизменяемую полезную нагрузку произвольного C++ типа; пакеты являются value-классами с семантикой подсчета ссылок, что позволяет копировать их с минимальными затратами. Граф  определяет пути передачи пакетов между узлами и управляет всей вычислительной логикой; он может иметь произвольное количество входов и выходов, а также поддерживает обратные циклы. Узлы, исторически называемые калькуляторами, являются основными вычислительными единицами, где происходит основная работа графа; каждый узел может иметь несколько входных и выходных портов, идентифицируемых тегом и/или индексом. Потоки  представляют собой соединения между узлами, по которым передаются последовательности пакетов с монотонно возрастающими временными метками. Боковые пакеты — это особый тип соединений, передающих единственный пакет с неопределенной временной меткой, который остается постоянным в течение всего времени выполнения графа.
>

### Негативные стороны модели MediaPipe
Модель MediaPipe имеет низкую устойчивость к перекрытиям, при которых она "додумывает" точки, генерируя вымышленные положения отсутствующих в кадре конечностей. Кроме того, модель показывает нестабильные результаты при отслеживании нескольких людей из-за проблемы «прыгающих» идентификаторов, а также демонстрирует заметное снижение точности при неблагоприятном освещении. Данную проблему можно решить так:  вычислять положение суставов через соседние, использовать многопользоовательский трекер и отправить предобработку перед созданием скелета.

>  ### Как запустить код?
> 1. Скачиваем файл [Value_position](./Value_position.py) и [data_set](./data_set)
> 2. Устанавливаем все необходимые библиотеки (вот это через терминал --> pip install mediapipe opencv-python numpy pandas matplotlib)

> 5. Если выбрали формат 1, то необходимо указать полный путь к изображению и тип этого изображения(Пример: C:\Users\Name\Desktop\VS\practika\data_set\1.png)
> 6. Если выбрали формат 2, то откроется камера
