# Assessment_of_human_posture № 8 from tr2
## Зачем это нужно: анализ движений
>[!TIP]
Оценка позы (pose estimation) — задача компьютерного зрения, решаемая методами машинного обучения и глубоких нейросетевых архитектур. Современные подходы на основе искусственного интеллекта позволяют анализировать визуальные данные (изображения и видеопоследовательности) для определения пространственного положения и ориентации человека или объекта. Решение задачи базируется на детекции ключевых точек (keypoints), аппроксимирующих кинематическую структуру объекта.
>
>Компьютерное зрение (computer vision) — подобласть искусственного интеллекта, в рамках которой применяются модели машинного обучения (включая сверточные и рекуррентные нейронные сети) для интерпретации визуальной информации на уровне пиксельных и семантических признаков.
Модель машинного обучения представляет собой параметрическую функцию, оптимизируемую для выявления закономерностей в обучающих данных с целью последующего прогнозирования или принятия решений. В рамках данной задачи используется архитектура pose_landmarker_heavy из библиотеки MediaPipe, характеризующаяся максимальной точностью среди реализаций семейства. Модель детектирует 33 ключевых точки (от области носа до фаланг пальцев стоп), что значительно превосходит типовую конфигурацию с 17 ключевыми точками, применяемую в ряде альтернативных решений. Выходными данными модели служат нормализованные координаты (значения в диапазоне [0,1], выраженные в долях относительно ширины и высоты изображения, а не в абсолютных пикселях) и трёхмерные координаты (x, y, z) в метрическом или нормализованном пространстве.
>
>Для оценки качества работы модели вводятся следующие метрики: Полнота (Recall) — доля истинно положительных ключевых точек, корректно обнаруженных моделью. Критична для минимизации пропусков значимых точек. Точность (Precision) — доля детектированных точек, действительно являющихся корректными ключевыми точками. Необходима для контроля ложных срабатываний. Видимость (Visibility) — показатель, характеризующий присутствие ключевой точки в кадре без учёта окклюзий или выхода за границы изображения. Данная метрика важна для различения «необнаруженной» и «физически отсутствующей/невидимой» точки. min_tracking_confidenc — пороговый параметр уверенности для механизма отслеживания (tracking) между кадрами. Повышение данного порога увеличивает робастность, но приводит к росту задержки обработки (latency) из-за необходимости повторной инициализации детектора. Таким образом, предложенный пайплайн обеспечивает баланс между точностью локализации ключевых точек и вычислительной эффективностью за счёт управления порогами уверенности и использованием нормализованного представления координат.

### Архитектура модели MediaPipe
>[!IMPORTANT]
>Архитектура MediaPipe построена по принципу графа обработки данных (dataflow graph), где поток данных направляется между узлами, образуя направленный ациклический граф (DAG), способный к ветвлению и слиянию потоков. Основной единицей передачи данных в этом графе является пакет (Packet), который содержит числовую временную метку (timestamp) и неизменяемую полезную нагрузку произвольного C++ типа; пакеты являются value-классами с семантикой подсчета ссылок, что позволяет копировать их с минимальными затратами. Граф (Graph) определяет пути передачи пакетов между узлами и управляет всей вычислительной логикой; он может иметь произвольное количество входов и выходов, а также поддерживает обратные циклы. Узлы (Nodes), исторически называемые калькуляторами (calculators), являются основными вычислительными единицами, где происходит основная работа графа; каждый узел может иметь несколько входных и выходных портов, идентифицируемых тегом и/или индексом. Потоки (Streams) представляют собой соединения между узлами, по которым передаются последовательности пакетов с монотонно возрастающими временными метками. Боковые пакеты (Side Packets) — это особый тип соединений, передающих единственный пакет с неопределенной временной меткой, который остается постоянным в течение всего времени выполнения графа.
>

### Как запустить код?
> [!CAUTION]
> 1. Скачиваем файл [Value_position](./Value_position.py) и [data_set](./data_set)
> 2. Устанавливаем все необходимые библиотеки (вот это через терминал --> pip install mediapipe opencv-python numpy pandas matplotlib)
> 3. Запускаем файл
> 4. В терминале выбираем формат(1 или 2)
> 5. Если выбрали формат 1, то необходимо указать полный путь к файлу
> 6. Если выбрали формат 2, то откроется камера
